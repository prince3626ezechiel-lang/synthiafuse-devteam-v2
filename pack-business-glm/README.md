# Pack Business — Système GLM · Kit de revente

Kit marketing pour revendre le **Pack Business** (13 compétences) en affiliation / PLR.
Contenu source : dossier Google Drive « SYSTÈME GLM » (formations vidéo).

## Contenu de ce dossier

| Fichier | Rôle |
|---------|------|
| `catalogue.json` | Catalogue structuré (compétences + modules), exploitable par un programme |
| `CATALOGUE.md` | Même catalogue, version lisible |
| `marketing/copy-de-vente.md` | Page de vente : accroches, argumentaire PAS, offre, garantie, FAQ |
| `marketing/reseaux-sociaux.md` | Scripts TikTok/Reels, carrousel, posts Facebook/WhatsApp |
| `marketing/emails.md` | Séquence de 4 emails / messages WhatsApp |
| `site/index.html` | Page de vente statique (HTML/CSS, SEO propre, responsive) |

## À personnaliser avant utilisation

Cherche et remplace ces champs :
- `{{LIEN}}` / `https://wa.me/VOTRE_NUMERO` → ton lien de commande ou WhatsApp
- `{{WHATSAPP}}`, `{{PRIX}}` (350 000 FCFA par défaut), `{{PRENOM}}`, `{{TON_NOM}}`
- `<link rel="canonical" href="https://exemple.com/">` → ton vrai domaine

## Mettre le site en ligne

Le fichier `site/index.html` est autonome (aucune dépendance). Héberge-le gratuitement sur
Netlify, Vercel, GitHub Pages ou Cloudflare Pages en glissant le dossier `site/`.

## ⚠️ Limite connue — repackaging PLR

Le pack est composé de **vidéos**. Mes outils ne transcrivent pas la vidéo, donc je n'ai pas pu
extraire le contenu enseigné pour en faire des ebooks/guides « repackagés ». Pour ce livrable :

1. Fournis les **transcriptions** des vidéos (ou les ebooks originaux s'ils existent), et
2. je les reformate en produit prêt à vendre (guide, ebook, bundle).

## ⚠️ Droits

Assure-toi de détenir les **droits de revente / affiliation** sur ce pack (PLR ou accord avec
le propriétaire `businesafric@gmail.com`) avant de commercialiser. Les textes fournis évitent
volontairement toute promesse de gains chiffrés non vérifiables.
